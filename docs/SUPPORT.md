# Support

This is a learning and portfolio project; it is provided without a support or availability guarantee.

- For reproducible defects, open a GitHub issue with the expected and observed behavior, relevant steps, and environment details. Use synthetic data and remove credentials and personal information.
- For feature ideas, open an issue describing the use case and how it fits the demo's evidence, human-review, and safety boundaries.
- For questions about Azure deployment, include the failing workflow step and sanitized error output. Never post OIDC tokens, Azure credentials, Vision keys, or private deployment logs.

Before opening an issue, check the README and existing issues. See [Contributing](CONTRIBUTING.md) for local validation steps.
