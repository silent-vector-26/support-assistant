# Community standards

Participation in this project is expected to be respectful, constructive, and focused on the work. Welcome people with different backgrounds and experience levels. Critique ideas and code, not people.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, publishing private information, and disruptive conduct in project discussions.

Project maintainers may edit or remove content that violates these standards and may restrict participation when necessary. Report concerns privately to the repository owner through GitHub; do not include sensitive information in a public issue.
