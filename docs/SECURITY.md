# Security policy

This repository is a portfolio demonstration, not a production service. It has public ingress in its optional Azure deployment, no application authentication, and ephemeral case state. Use fictional information only.

## Reporting a vulnerability

Please do not disclose credentials, personal information, or exploitable details in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use **Security → Advisories → Report a vulnerability**. Otherwise, contact the repository owner through GitHub and request a private channel before sharing details.

Include the affected component, impact, reproduction conditions that do not expose real data, and any suggested mitigation. Do not test against Azure resources or deployments you do not own or have explicit permission to assess.

## Supported versions

Only the current default branch is maintained. This project does not provide a service-level or security-update guarantee.
